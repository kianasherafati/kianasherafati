# Maintaining this profile

The root README.md is displayed at https://github.com/kianasherafati when this public repository is named kianasherafati. Keep current student status and project descriptions up to date.

## Add a professional portrait later

1. Add your chosen photograph as `assets/profile.jpg` in this repository. A square crop around 400-600 pixels wide is sufficient. Remove location metadata before uploading.
2. In README.md, replace the `PORTRAIT_INSERT` comment with:

```html
<p><img src="assets/profile.jpg" alt="Kiana Sherafati" width="112"></p>
```

3. Preview the README and commit both files together. The image sits below the contact links without changing the rest of the layout.

There is deliberately no active image reference until the photograph exists. No external widgets, generated portraits, or image services are required.
